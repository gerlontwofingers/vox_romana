DEBATE TEMPLATE 02

PURPOSE
This template is designed for debates that should sound more dynamic, more interruptible, and more conversational than template_01 while still remaining easy to parse with Python.

IMPORTANT FOR DEEPSEEK
- Populate this template one segment at a time.
- Keep all field names and delimiter lines exactly as written.
- Do not rename keys.
- Do not remove required fields.
- Use NONE when a field does not apply.
- Every segment must repeat the required debate metadata.
- The same debate must keep the same TEMPLATE_ID, DEBATE_ID, and DEBATE_TITLE across all segments.
- SEGMENT_ORDER must increase by 1 for each new segment of the same debate.
- GLOBAL_EVENT_ORDER must continue increasing across all segments of the same debate.
- This template allows fragments, interruptions, reactions, and overlapping delivery.
- If an event is cut off, use COMPLETION_STATUS: cut_off or fragment as appropriate.
- If an event overlaps the previous event, set OVERLAP_WITH_PREVIOUS: YES.
- If an event interrupts the previous event, set INTERRUPTS_PREVIOUS: YES.
- If there is no moderator, set MODERATOR_MODE to NONE.
- If there is no audience, set AUDIENCE_PRESENT to NO and AUDIENCE_PARTICIPATION to NONE.
- If the audience is present but silent, set AUDIENCE_PRESENT to YES and AUDIENCE_PARTICIPATION to NO.
- This output will be parsed and merged later, so structural consistency is required.

FORMAT RULES
- Use the exact start and end markers shown below.
- Do not add markdown.
- Keep values on one line.
- Use semicolons for list-style values.
- Allowed EVENT_KIND values: speech; interruption; reaction; moderation; stage_direction
- Allowed TONE_SHIFT values: neutral; calm; firm; passionate; skeptical; reflective; urgent; confrontational; respectful; analytical; playful; solemn; escalating; deflective
- Allowed VOLUME values: soft; moderate; loud; rising; falling
- Allowed PACE values: slow; medium; fast; accelerating; decelerating
- Allowed PAUSE values: none; short; medium; long
- Allowed COMPLETION_STATUS values: complete; cut_off; fragment; trailing; handoff

HOW TO USE THIS TEMPLATE
1. Copy the full segment template for each generated piece.
2. Fill in all metadata before adding events.
3. Add one or more EVENT blocks.
4. Keep GLOBAL_EVENT_ORDER increasing across the full debate.
5. Set IS_FINAL_SEGMENT to YES only on the final segment.
6. Use CARRY_FORWARD to tell the next generation pass what to continue.

OPTIONAL GUIDANCE
- Use EVENT_KIND: reaction for audible reactions such as laughter, applause, boos, or collective surprise.
- Use EVENT_KIND: stage_direction for non-spoken ambience or scene-level actions.
- Use EVENT_KIND: interruption when a speaker cuts in before another speaker has fully finished.
- Use EVENT_KIND: moderation for moderator rule-setting, time warnings, or redirection.
- TEXT may be NONE for pure reaction or stage_direction events.
